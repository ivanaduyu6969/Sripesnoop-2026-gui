The mockup shows the dark-themed interface with:
 
Title bar with the "Stripe Snoop Modern" branding
 
Control buttons (Load Bitstream, USB Reader Mode, Save to TXT, Clear)
 
Audio Spectrum Visualizer with the F2F signal showing the ~1 kHz (green, "0" bits) and ~2 kHz (red, "1" bits) frequency peaks, plus a swipe progress bar at 67.3%
 
Three Track tabs — Track 1 (IATA) and Track 2 (ABA) populated with decoded Visa card data, Track 3 showing empty state
 
Card Analysis panel with detected card type, issuing bank, LRC status, and timestamp
 
Status bar at the bottom
